## Workflow
1. Study the census below (already run for you — do not redo it).
2. Characterize this job's drawing convention from the census alone: prefix
   scheme, proposed-vs-existing signals, apparent CAD-product template style.
   Infer from the data; nothing is hardcoded and no real firm identity exists
   anywhere in this pipeline.
3. Call `dwg_corpus_lookup` to fetch past jobs' census fingerprints; judge
   which past job most resembles this one *behaviorally* and fetch its
   completed qty sheet as few-shot grounding for the mapping step.
4. Extract quantities layer by layer with `src.dwg_qty` functions (ad hoc code
   only where the library has a gap — mark those results).
5. Map extracted quantities into qty_tbl rows, using the fill-in template
   below as your reference for exact row labels/qualifiers — copy a
   populated row's `Work type` text exactly, do not compose your own labels
   from scratch.
6. Present the final table — populated rows only, per field rule 17, not
   the full blank template — plus the Case A / Case B flag lists, then
   offer to place the table into a document for XLSX download.
